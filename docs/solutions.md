# Codeweald — Instructor Answer Key

> **Generated by `npm run solutions` from `content/`. Do not edit by hand.**
> Codeweald is a self-paced course with no teacher features in the app. This document lets
> instructors prepare for students' questions. Reference solutions are *not* included in the
> game itself. If this repository is public, students can read this file too.

Each quest checks behavior, not exact text, so other correct programs also pass. The
"common mistakes" are the targeted hints students see when the checker spots that mistake.
See [curriculum-map.md](curriculum-map.md) for the full course outline and the
misconceptions to watch for in each region.

## Region 1 — Hearthvale Village

**Concepts:** programs as ordered steps; print(); strings; comments; reading an error

**Byte's analogy:** A program is like a recipe. The computer is a very literal cook. It does each step in order, top to bottom, exactly as written. Even if you write "add 100 eggs."

### Byte's First Steps

`r1-q1-first-steps`

- **Type:** predict
- **Learning outcome:** Predict where the hero ends up when move instructions run in order, top to bottom.
- **CSTA:** 2-AP-10 · **About 6 min**
- **Goal (as students see it):** Read the program and predict where the hero will stop. Then run it to check.

**Code students read:**

```python
from codeweald import hero
hero.move("right", 4)
hero.move("down", 2)
hero.move("left", 2)
hero.move("down")
```

**Answers:**

- When the program ends, what is the hero standing next to? → **The market stall**. Right 4, down 2, left 2, then down 1. Step by step, that lands the hero right beside the market stall.
- Which move does the hero make first? → **Right 4 steps**. Python starts at the top. The first move line is `hero.move("right", 4)`.

**Hints (free, in this order):**

1. Put your finger on the hero. Read one line at a time and move your finger the same way.
2. `hero.move("right", 4)` means 4 steps to the right. `hero.move("down")` means just 1 step down.
3. (code example)

Trace it step by step:
```text
line 2: right 4 -> the hero is near the top right
line 3: down 2  -> the hero is on the well's row
line 4: left 2  -> the hero walks back toward the middle
line 5: down 1  -> the hero stops next to ____
```

### Hello, Hearthvale!

`r1-q2-hello-hearthvale`

- **Type:** investigate
- **Learning outcome:** Explain what print() shows on the Scroll of Output by running a program and answering questions about it.
- **CSTA:** 2-AP-11 · **About 6 min**
- **Goal (as students see it):** Run the program, watch the Scroll of Output, and answer Pip's questions. Try the changes the questions ask for!

**Code students run:**

```python
print("Hello, Hearthvale!")
print("The bread is warm.")
print("The chickens are loud.")
```

**Answers:**

- Run the program. How many lines appear on the Scroll of Output? → **3**. Three `print` instructions make three lines of output.
- Swap lines 1 and 2 in the Spellbook, then run it again. What changes? → **The first two lines of output swap places too.**. The output follows the order of the code. Change the order, change the output.
- Now remove the quotes around `Hello, Hearthvale!` and run it. What happens? → **Python shows an error.**. Text needs quotes. Without them, Python tries to read the words as code and gets confused.
- Finish the sentence with one word: `print` ____ text on the Scroll of Output. → **shows / writes / displays / prints / puts**. `print` shows text on the Scroll of Output.

**Hints (free, in this order):**

1. Press Run first, then look at the Scroll of Output. That's where `print` puts its words.
2. Each `print(...)` makes one new line. The words between the quotes are what you see.
3. (code example)

Here's how the Scroll looks for the first line:
```text
Hello, Hearthvale!
____
____
```

### The Path to the Well

`r1-q3-path-to-the-well`

- **Type:** parsons
- **Learning outcome:** Arrange move and say instructions in order so the hero reaches the well and greets the miller.
- **CSTA:** 2-AP-10 · **About 7 min**
- **Goal (as students see it):** Put the lines in order. The hero must walk to the miller without bumping into anything. Then the hero says good morning.

**Reference solution** (other correct answers also pass — the checks test behavior):

```python
from codeweald import hero
hero.move("right", 3)
hero.move("down", 2)
hero.move("right")
hero.move("down")
hero.say("Good morning, Miller!")
```

**Distractor lines (not used):** `hero.move("up")`

**Common mistakes and the feedback students get:**

- *bonked* — Bonk! The hero walked into a hedge. Python did exactly what the lines said, in order. Trace the path with your finger and check which move should come first.
- *said-too-early* — You said good morning before you got to the miller! The hello should be the very last instruction, after all the moves.
- *wrong-spot* — The hero didn't stop next to the miller. Count the steps again. Remember, one scrap doesn't belong in the program at all.

**Hints (free, in this order):**

1. The hero starts at the top left. Which way can it go first without hitting the hedge?
2. First go right along the top row, then down the gap. Say good morning only when you're next to the miller. The line `hero.move("up")` isn't needed.
3. (code example)

```python
from codeweald import hero
hero.move("right", 3)
hero.move("down", 2)
____
hero.move("down")
hero.say("Good morning, Miller!")
```

### Notes for the Baker

`r1-q4-notes-for-the-baker`

- **Type:** modify
- **Learning outcome:** Use # comments to explain what each part of a program does.
- **CSTA:** 2-AP-19 · **About 7 min**
- **Goal (as students see it):** Turn the sock line into a comment, then add at least two comments that say what the parts of the program do.

**Starter code:**

```python
print("Baker Bun's Order")
print("12 loaves of bread")
print("6 cherry pies")
print("1 pickled sock")
print("Thank you!")
```

**Reference solution** (other correct answers also pass — the checks test behavior):

```python
# The title of the order
print("Baker Bun's Order")
# The food we need
print("12 loaves of bread")
print("6 cherry pies")
# print("1 pickled sock")
# A polite goodbye
print("Thank you!")
```

**Common mistakes and the feedback students get:**

- *no-hash* — Python tried to run your note as code and got confused. A note for humans must start with `#`, like `# The food we need`.
- *sock-still-prints* — That pickled sock is still on the Scroll! Put a `#` at the very start of its line. Then Python will skip it.
- *too-few-comments* — The sock is gone. Nice! Now add at least two comments that label the parts of the program, like `# The title` and `# The food we need`.

**Hints (free, in this order):**

1. Which line shouldn't be on the order at all? What symbol makes Python skip a line?
2. Put `#` at the start of the sock line. Then add a comment line above the title and another above the food, like `# The food we need`.
3. (code example)

```python
# The title of the order
print("Baker Bun's Order")
____
print("12 loaves of bread")
print("6 cherry pies")
# print("1 pickled sock")
print("Thank you!")
```

### The Crier's Crooked Announcement

`r1-q5-criers-crooked-announcement`

- **Type:** fix
- **Learning outcome:** Use the line number in an error message to find and fix a missing quote and a missing closing parenthesis.
- **CSTA:** 2-AP-17 · **About 8 min**
- **Goal (as students see it):** Fix the two bugs so the crier's announcement prints all three lines.

**Starter code:**

```python
print("Hear ye! Hear ye!)
print("Market at noon!"
print("Bring your own basket.")
```

**Reference solution** (other correct answers also pass — the checks test behavior):

```python
print("Hear ye! Hear ye!")
print("Market at noon!")
print("Bring your own basket.")
```

**Common mistakes and the feedback students get:**

- *unclosed-quote* — A quote opened but never closed. Look at the line in the error message. Every opening `"` needs a closing `"` right before the `)`.
- *unclosed-paren* — A `(` was never closed. Look at the line in the error message and add a `)` at the end of it.
- *words-changed* — No more errors. Great! But the words on the Scroll don't match the crier's script. Check the spelling and the punctuation.

**Hints (free, in this order):**

1. Press Run and read the error message. Which line does it point to?
2. Line 1 is missing a closing quote `"`. After you fix it, run again. Line 2 is missing a closing `)`.
3. (code example)

```python
print("Hear ye! Hear ye!")
print("Market at noon!"____
print("Bring your own basket.")
```

### Paint the Welcome Sign

`r1-q6-welcome-sign`

- **Type:** make
- **Learning outcome:** Write a program with several print() calls that prints a three-line welcome sign exactly as shown.
- **CSTA:** 2-AP-11 · **About 8 min**
- **Goal (as students see it):** Write three print() lines that print the welcome sign exactly as shown.

**Starter code:**

```python
# Paint the sign: one print() for each line.
```

**Reference solution** (other correct answers also pass — the checks test behavior):

```python
# Paint the sign: one print() for each line.
print("Welcome to Hearthvale!")
print("Try Bun's Bakery")
print("Mind the chickens.")
```

**Common mistakes and the feedback students get:**

- *apostrophe-quote* — The apostrophe in `Bun's` ends your text early! When text has an apostrophe, use double quotes around it: `print("Try Bun's Bakery")`.
- *one-print* — The sign looks right, but Pria wants one `print()` for each line. Split it into three `print()` lines.
- *wrong-text* — So close! Compare your Scroll with the sign, one line at a time. Capital letters, spaces and the full stop all count.

**Hints (free, in this order):**

1. The sign has three lines. How many `print()` instructions do you need?
2. Copy each line of the sign into its own `print("...")`. Line 2 has an apostrophe, so use double quotes around it.
3. (code example)

```python
print("Welcome to Hearthvale!")
print(____)
print("Mind the chickens.")
```

### The Village Crier Bug 🐛 boss

`r1-boss-village-crier-bug`

**Boss:** The Village Crier Bug (Clangle). Fix the announcement in three phases. Then Clangle turns back into a friendly firefly.

#### Phase 1: Unjam the bell

- **Type:** fix
- **Learning outcome:** Use error messages to find and fix errors that stop a program from running.
- **CSTA:** 2-AP-17 · **About 4 min**
- **Goal (as students see it):** Fix the two bugs so the announcement runs and prints all three lines.

**Starter code:**

```python
print("Hear ye, hear ye!")
Print("The market moves to the square.")
print("The fair starts at noon!)
```

**Reference solution** (other correct answers also pass — the checks test behavior):

```python
print("Hear ye, hear ye!")
print("The market moves to the square.")
print("The fair starts at noon!")
```

**Common mistakes and the feedback students get:**

- *open-quote* — The text on one line never ends. Find the line in the error message and add the missing closing quote `"` before the `)`.
- *capital-p* — Python is picky about capital letters. `Print` is not the same as `print`. Change the capital P to a small p.
- *words-changed* — The errors are gone, but some words changed. Compare each line with the starter code.

**Hints (free, in this order):**

1. Run it and read the error message. Which line does it point to?
2. Line 3 is missing a closing quote. After you fix it, run again. Then look at how line 2 is spelled.
3. (code example)

```python
print("Hear ye, hear ye!")
____("The market moves to the square.")
print("The fair starts at noon!")
```

#### Phase 2: Words in order

- **Type:** fix
- **Learning outcome:** Arrange print statements so the output matches a required order.
- **CSTA:** 2-AP-17 · **About 4 min**
- **Goal (as students see it):** Reorder the print lines so the output matches the crier's script exactly.

**Starter code:**

```python
print("The fair starts at noon!")
print("Hear ye, hear ye!")
print("Bring a friend and a basket.")
```

**Reference solution** (other correct answers also pass — the checks test behavior):

```python
print("Hear ye, hear ye!")

```

**Common mistakes and the feedback students get:**

- *first-line* — Every announcement starts with "Hear ye, hear ye!" Move that line to the top. Python runs the lines from top to bottom.
- *order* — A good start! The words are all there, but some lines are in the wrong order. Compare the Scroll with the script, one line at a time.

**Hints (free, in this order):**

1. Which line should the crier shout first?
2. The order of the print lines is the order of the Scroll. Move each line to match the script, top to bottom.
3. (code example)

#### Phase 3: Ring it out

- **Type:** modify
- **Learning outcome:** Document a program with comments that explain each part.
- **CSTA:** 2-AP-19 · **About 4 min**
- **Goal (as students see it):** Walk the hero to the tile in front of the podium. Then say "Hear ye!". Add a comment above the walking part, and one above the talking part.

**Starter code:**

```python
from codeweald import hero
```

**Reference solution** (other correct answers also pass — the checks test behavior):

```python
from codeweald import hero
# Walk to the podium
hero.move("right", 3)
hero.move("up")
# Ring out the news
hero.say("Hear ye!")
```

**Common mistakes and the feedback students get:**

- *say-no-parens* — `hero.say` needs brackets and quotes to work: `hero.say("Hear ye!")`. Without the `( )`, nothing happens.
- *not-there* — The hero isn't in front of the podium yet. The podium is 3 steps right and 2 steps up from the start. Stop on the tile just below it.
- *no-comments* — The hero rang out the news. Now leave notes for the next crier: a `#` comment above the walking part and another above the speaking part.

**Hints (free, in this order):**

1. Where is the podium compared to the hero? Count the steps right, then up.
2. Move right 3, then up 1. Then use `hero.say("Hear ye!")`. Put a line starting with `#` above each part.
3. (code example)

```python
from codeweald import hero
# Walk to the podium
hero.move("right", 3)
hero.move(____)
# Ring out the news
hero.say("Hear ye!")
```

### Knowledge check

1. What does `print()` do? → **It shows text on the Scroll of Output.**. `print()` shows text on the Scroll of Output. No paper needed!
2. What will this print?

```python
print("Bake")
print("Cool")
print("Eat")
```

   Answer:

```text
Bake
Cool
Eat
```

   Python runs the lines in order, top to bottom, so the words come out in that order.

3. Which line will Python skip? → **# Feed the chickens**. A line that starts with `#` is a comment. Python skips it.
4. An error message says "line 3". Where do you look first? → **Line 3 of my code**. Start at line 3. Sometimes the real slip is just above it, so check that line too.
